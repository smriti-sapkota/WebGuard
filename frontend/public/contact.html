No bots on the other end
TL;DR: The fastest way to reach us is the project repository on GitHub. Open an issue and we'll take it from there.

Who we are

WebGuard is a student project from Tribhuvan University, BSc CSIT 7th semester. Real students, real coffee, real deadlines.

GitHub (best option)

Open an issue on the WebGuard repository for bugs, ideas and questions. The README also has setup and contribution details.

Something looks off?

Wonky layout or a button that won't click? Tell us your browser and what you were doing. Screenshots make us very happy.

Scanner acting weird?

Scan stuck or a result that looks wrong? Include the target type (never your passwords!) and the scan ID from the Scanner page.

Security issues & data requests

For vulnerabilities, see our security page. To delete your account, mention it in a GitHub issue without posting private details, and we'll sort out the rest.

We usually reply within a few days. Student schedules are unpredictable.
